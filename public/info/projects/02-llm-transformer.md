- Implemented a decoder only Transformer language model from scratch in PyTorch using the Tiny Shakespeare dataset, building BPE tokenization, RoPE embeddings, RMSNorm, feed-forward networks, and end-to-end model components.
- Implemented and evaluated Multi-Head Attention (MHA), Grouped-Query Attention (GQA), and Multi-Head Latent Attention (MLA), comparing accuracy and performance metrics and using MLA in the final architecture.

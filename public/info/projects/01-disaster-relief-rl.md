- Designed an OpenEnv-based disaster relief environment simulating triage, resource allocation, dynamic replanning, terrain constraints, communication failures, and time-critical operations for **multi-agent RL training**.
- **Designed a reward system and multi-metric grading** process to evaluate agent decisions for covering task completion, response time, correct resource use, and error handling while preventing agents from reward hacking.
- Deployed the end-to-end environment as a **Dockerized FastAPI** service with standardized reset, step, grade, and state openENV APIs for integration with RL training workflows.

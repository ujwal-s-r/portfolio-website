## Key Highlights

- Eliminated the $O(N^2)$ memory footprint of standard attention by tiling query, key, and value matrices directly in GPU shared memory (SRAM).
- Computed exact attention outputs without ever writing the full attention matrix to High Bandwidth Memory (HBM).
- Benchmarked across context lengths from 2k to 64k tokens, yielding up to 3.8x speedup over standard PyTorch SDPA without flash optimizations.

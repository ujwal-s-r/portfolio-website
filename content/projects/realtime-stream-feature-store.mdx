## Overview

Designed and implemented a distributed dual-storage feature store serving both low-latency online ML models and high-throughput offline batch training sets without data leakage or train-serve skew.

### System Architecture

- **Ingestion & Processing**: Apache Flink streaming engine consuming 500,000+ financial transaction events per second from partitioned Kafka topics.
- **Dual-Storage Engine**:
  - **Online Storage**: Clustered Redis with pipelined binary serialization for sub-12ms P99 feature lookup.
  - **Offline Storage**: Delta Lake on object storage with automatic compaction and Z-order indexing for time-travel queries.
- **Unified Query Layer**: High-performance gRPC gateway serving synchronized point-in-time correct features for model inference.

## Overview

In clusters with heterogeneous accelerator topologies, naive job placement creates massive PCIe and cross-socket NVLink bandwidth bottlenecks. This scheduler models inter-GPU bandwidth as a graph flow problem to place communicating model shards optimally.

### Key Capabilities

- **Automated Topology Discovery**: Probes NVLink mesh, PCIe bus distance, and NUMA node proximity on node boot.
- **ILP-Based Job Placement**: Uses an Integer Linear Programming solver to place pipeline stages along maximum bandwidth links.
- **Custom K8s Controller**: Exposes custom resource definitions (`GpuJob`) for declarative ML workload scheduling.

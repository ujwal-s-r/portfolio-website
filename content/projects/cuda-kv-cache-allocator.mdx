## Overview

Default `cudaMalloc` and PyTorch caching allocators introduce device synchronization locks and non-deterministic overheads during dynamic LLM decoding loops. This project provides a dedicated lock-free GPU memory allocator specifically designed for tensor cache pools.

### Architectural Innovations

- **Lock-Free Free-Lists**: Implemented atomic CAS (Compare-And-Swap) linked lists running directly on device threads.
- **Hierarchical Memory Bins**: Divided memory pool into pow2 cache line aligned blocks (64B to 64MB) to guarantee 100% coalesced memory access.
- **Nsight Systems Profiling**: Verified 0 host-device synchronization stalls across 100k continuous inference iterations.

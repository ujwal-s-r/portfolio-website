## Overview

Modern Large Language Model serving suffers from quadratic memory overhead and extreme memory fragmentation when processing concurrent variable-length requests. This project implements a high-throughput, low-latency distributed serving runtime optimized for high concurrency.

### Key Architectural Highlights

- **Custom PagedAttention Kernel**: Replaced standard contiguous KV cache allocation with a virtual page table mapping dynamic blocks in high-bandwidth GPU memory (HBM3e).
- **Continuous Chunked Prefill & Decoding**: Implemented iteration-level scheduling that overlaps prefill phases with decode steps to eliminate GPU idle bubbles.
- **Tensor & Pipeline Parallelism**: Built custom NCCL communication hooks for efficient cross-node model sharding across 8× H100 SXM5 instances.

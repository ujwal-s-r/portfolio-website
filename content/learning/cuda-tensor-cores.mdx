## Deep Dive: Low-Level GPU Micro-Architecture

Currently exploring hardware-level optimization techniques for extreme tensor throughput:

- **Asynchronous Copy (TMA)**: Bypassing register file bottlenecks by copying data directly from Global Memory (HBM) to Shared Memory (SRAM).
- **Warp-Group MMA (WGMMA)**: Writing low-level PTX assembly for Hopper tensor cores to achieve near-peak compute utilization.
- **Warp Specialization**: Partitioning warps inside a thread block into dedicated Producer warps (DMA/Memory) and Consumer warps (Math/MMA).
